# Staff field guide

The Dashboard shows player search, current staff priorities and game summaries. Open Crates, Dragon event, Voting, Piñata, Fishing, Player shops or MCPets directly from the sidebar or their cards. Each system starts with a few useful figures; expand rankings, event rows or catalogue entries for the complete evidence. Use Metric explorer for other measurements and exports.

1. Find the player by username or UUID. Check the server and timestamp before acting.
2. Add a factual profile note or watch instruction. A case is optional. Archive resolved instructions.
3. Pin a relevant chat message to keep its exact content beyond raw-log retention. Add screenshots or supporting files to the profile. Private evidence needs the extra private-message permission.
4. Open a case from the player or the relevant message when an investigation needs a recorded outcome. Repeated clicks on the same source message open the existing case.
5. Treat a dupe/exploit flag as a review request. Read the context, check logs/CoreProtect and document what you verified. A keyword match is never an automatic punishment.
6. Use grouped diagnostics to inspect repeated errors across timestamps. Use Plugins & Connections to distinguish confirmed native coverage from missing data.
7. Crate batches count their actual number of openings. Reward grants and opening batches are separate measurements. Configured weights are not guaranteed observed drop percentages.
8. QuickShop values describe successful transactions. MCPets summons are not purchases. Historical Dragon snapshots are not added a second time to new event rankings.
9. Website roles and Minecraft LuckPerms groups are separate. Only the Owner creates staff accounts and changes HQ role permissions.
10. For Dragon, `/dragon status` shows the phase. `/dragon stop` evacuates players and removes only a managed clone. Never delete the template or main world to solve a reset problem.

Choose Cherry Blossom for plum-and-rose Sakura colours, or Clear Light for a light background. Appearance and larger text are at the bottom of the sidebar. On phones, open the menu for the same direct destinations; tables become labelled cards and messages and commands wrap inside the screen.
