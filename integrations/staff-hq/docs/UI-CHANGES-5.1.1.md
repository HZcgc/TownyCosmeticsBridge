# Staff HQ 5.1.1 interface changes

Staff can now open each game directly from the sidebar or a dashboard summary card. Crates and Dragon no longer require finding a statistics sub-tab.

| Area | Result |
| --- | --- |
| Navigation | Task-based groups with direct Crates, Dragon, Voting, Piñata, Fishing, Player shops and MCPets destinations. |
| Dashboard | Player search, actual server-report status, staff priorities and seven game summaries appear before secondary detail. Cases and alerts use short clickable entries. |
| Game overview | One visible card per available system. Advanced measurements stay in Metric explorer; existing statistics bookmarks still resolve. |
| Topic pages | Period/server filters, key figures, daily trends, top players, recorded activity and expandable evidence. Full rankings and catalogues remain available. |
| Dragon | Native event statistics and historical lifetime records are visibly separate. |
| Catalogues | Pages of 24 configured entries with expandable fields, including pet offers and their recorded Tebex commands. |
| Cherry Blossom | Plum and rose palette, actual Sakura vector illustrations, pink/lavender charts and readable dark text on blush buttons. |
| Mobile | Compact cards, wrapped evidence and an accessible slide-out menu with Escape/backdrop dismissal. |
| Roles | Existing permissions guard both direct links and destination pages. Private chat counts retain their additional permission gate. |

This is a webspace-only update. It updates the HQ role presets once at schema 10; the connector protocol, key balances, pet grants and Minecraft permissions stay unchanged. Existing profile workflows and record retention are retained. No data is fabricated for systems without collected events; absent coverage is still reported by Connections.

## Follow-up changes

Chart tooltips follow the pointer and flip at the edges. The Staff guide uses the normal Documents editor with a persistent document ID. Helper/Moderator/Admin presets are applied once, with a rollback snapshot, and subsequent Owner edits are retained. All permissions are listed in ROLE-PERMISSIONS.md.
